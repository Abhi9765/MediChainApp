# **App Name**: MediChain

## Core Features:

- Inventory Management: Add, update, and remove stock, tracking batch and expiry.
- Stock Transfer Requests: Request transfers of items between departments or hospitals, which must then be approved by the location to receive the item
- Smart Expiry Notifications: Notify staff when items are near expiry, using basic threshold
- Procedure-Based Kit Definition: Define kits for common procedures (e.g., 'Cataract Surgery Kit') and automatically reserve the included items from stock.
- Drug Interaction Checker Tool: Use the OpenFDA or RxNorm API to find potential drug interactions when a specific drug is selected.
- Basic Analytics Dashboard: Shows basic metrics like wastage, expiry losses.
- Mobile QR code stock scanning: Mobile users will be able to scan the QR code using the phone camera in order to add new items to inventory or select existing ones.

## Style Guidelines:

- Primary color: Calm light blue (#89CFF0) to evoke trust and cleanliness.
- Background color: Very light gray (#F5F5F5), almost white.
- Accent color: Soft green (#90EE90) for positive actions like 'Add Stock'.
- Body and headline font: 'PT Sans', a clean, humanist sans-serif suitable for both.
- Use clear, standard icons for inventory actions, alerts, and navigation.
- Maintain a clean, tabular layout for inventory display and forms.
- Use subtle animations for state changes, like stock updates or expiry alerts.
